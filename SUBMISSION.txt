Title
AuditStrata - Commit-seal-reveal audit sampling

Notes / Description
Built AuditStrata, a reusable GenLayer Intelligent Contract for stratified audit sampling. A distinct auditor commits a random seed hash before the owner supplies records; the owner then seals an immutable population digest. Validators classify each public record into a declared stratum, and deterministic seed-derived ordering draws a reproducible cross-stratum sample. Auditor acknowledgements gate final closure. GenVM lint and strict type checking pass; 21 direct security tests and a five-validator integration flow pass. A fresh two-wallet StudioNet run reached CLOSED state and proved exact deployed-source equality.
