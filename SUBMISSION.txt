Title
AuditStrata - Stratified deterministic audit sampling

Notes / Description
Built AuditStrata, a reusable GenLayer intelligent contract for stratified deterministic audit sampling. Consensus assigns records to a closed stratum set; seeded hashing and round-robin selection create a reproducible cross-stratum sample. One deployment supports multiple independently keyed records and callers. Inputs are public, caller-supplied snapshots; the contract does not automatically fetch or authenticate sources and moves no funds. GenVM lint, strict type checking, 4 direct tests and one five-validator GLSim flow passed. StudioNet verified successful finalized intelligent execution, final-state readback and matching deployed source.
